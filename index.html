Remaining Gaps — Honest & Labeled

These are not hidden assumptions. Every gap is documented with the exact Mathlib version where it will close.

arithmetic_admissibility

Requires Meyer 2005 spectral-Weil explicit formula + positivity. SpectralWeil.lean documents the exact path. Will close when Mathlib formalizes the explicit formula.

hurwitz_three_doublings

Hurwitz's theorem — ℝ, ℂ, ℍ, 𝕆 are the only normed division algebras — is not yet in Mathlib 4.19.0. Will close in a future Mathlib version.

Adelic infrastructure (Tate thesis, Fujisaki, L² on K')

Awaiting Mathlib.NumberTheory.NumberField.Adeles. The Mathlib number theory community is actively developing this. All dependent theorems are axiomatized cleanly with clear documentation.

thm:link6 (QFT axioms)

The proof of c₂D = κ₀·c₄D^Weyl relies on four established physics results (Weinberg 1965, Cachazo-Strominger 2014, Capper-Duff 1974, Adler-Bardeen 1969) that are standard QFT but not yet in Mathlib. Axiomatized with full citations.

How to Verify Yourself

Every proof in this repository can be independently checked by anyone with Lean 4 installed. The machine does not accept arguments from authority.

git clone https://github.com/GoldenPhysicsProject/GPPVerify
cd GPPVerify
lake exe cache get
lake build

If it builds green — the proofs are correct. No peer review required.
