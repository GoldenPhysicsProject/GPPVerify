\section{Tree-to-Loop Topology (Shadow-Pair Sewing)}
\label{sec:tree-loop-sewing}

From Toupin, \emph{Loop Integrands Hidden in Trees: Explicit Extraction by Double Shadow

\begin{theorem}[Pair-Sewing Cycle Rank]
  \label{thm:pairsewing-cyclerank}
  \lean{GppTreeLoopSewing.pairSewing_cycleRank}
  \leanok
  For a connected cubic tree with $n = 4+2L$ external leaves ($V_T = n-2$ trivalent
  vertices, $I_T = n-3$ internal edges), sewing $L$ disjoint pairs among the designated
  $2L$ extra leaves leaves $4$ external legs and $I = I_T + L = 3L+1$ internal edges, with
  cycle rank $\beta_1 = I - V_T + 1 = L$. Proved for all $L$ by direct computation on the
  vertex/edge counts (\texttt{omega}); no combinatorial machinery beyond arithmetic is
  needed since only the counts, not an explicit graph object, are formalized here.
\end{theorem}

\begin{corollary}[One-Loop Box Specialization]
  \label{cor:sixpoint-oneloop}

\section{The \texttt{True}-Stub Convention (not axioms, not sorries)}

Roughly twenty further declarations named in earlier snapshots of this chapter under
``Infrastructure Axioms'' and ``Infrastructure Sorries'' --- e.g.\ \texttt{peter\_weyl\_K1},
\texttt{weil\_explicit\_formula}, \texttt{K1\_haar\_probability}, \texttt{lovelock\_theorem},
\texttt{celestial\_amplitude\_has\_cut} --- were spot-checked against the current tree while
re-auditing this chapter (2026-08-15) and are \textbf{no longer axioms}: each is now a
\texttt{theorem foo : True := trivial}, the repo's deliberate, documented convention for
parking an open result as a vacuous statement carrying a doc comment that names the precise
upstream gap, rather than smuggling it in as an axiom or leaving a live \texttt{sorry}. A
few others (\texttt{shadow\_breaking\_gives\_abundance}, \texttt{shadow\_unitarity\_
abundance\_pos}) turned out to be fully proved theorems, not placeholders at all.

There are currently \textbf{133} such stubs across 24 files. \textbf{This is the single
most important caveat for reading this repo}: a file containing only stubs reports zero
sorries and zero axioms --- the cleanest possible bill of health --- while asserting
nothing. The full per-file, per-thread ledger (which stub covers which named gap, and the
plan for closing it) lives in \texttt{docs/FORMALIZATION\_PLAN.md} in the repository, not
in this blueprint; it is updated in the same PR that advances any thread.

\textbf{Sorry count: 0.} Enforced by a dedicated CI gate on every push
(\texttt{.github/workflows/build.yml}). Declarations named in earlier snapshots of this
chapter as carrying a live \texttt{sorry} have each since been resolved --- closed with a
real proof, converted to a named axiom above, or converted to a \texttt{True}-stub.
