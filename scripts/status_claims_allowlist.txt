# Format, one entry per line:
#
#     PATH :: LINE-REGEX :: REASON
#
# PATH is a repo-relative path or glob. LINE-REGEX is a Python regex the hit line
# must match; `*` exempts every hit in the file and is used only where the whole
# file is a single record of the stated kind. REASON is required: it names the
# adjudicated class the line belongs to. An entry without a reason does not parse.
#
# The classes (PR #672's adjudication): OPEN registries and `open_` stub records;
# THEOREM/LEAN/OPEN/KILLED label lines; hypothesis statements naming what a proved
# result takes; the proved-false ledger; correction and retirement records;
# definitional and framework-claim guards; dated historical notes, kept as written
# (editing a dated record to match today's tree would falsify the record).
#
# A NEW disclaimer does not get an entry here. It gets rewritten: state what is
# proved and name the hypotheses it takes.
