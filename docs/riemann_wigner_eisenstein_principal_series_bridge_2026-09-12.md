# Exact Riemann--Wigner / Eisenstein principal-series bridge

Date: 2026-09-12

## 1. Starting point from the current RH manuscript

The exact Wigner--Bessel expansion already derived for Riemann's Fourier density is

    W_Xi(a,t)
      = 4 pi^2 e^(5a)
        sum_{n>=1} n^2 lambda_t(n)
        B_t(2 pi n e^(2a)),

with

    lambda_t(n)
      = n^(it) sigma_{-2it}(n)
      = sum_{d|n} (n/d^2)^(it)  in R,

and

    B_t(T)
      = (T^2+9) K_{it}(T) + 6T K'_{it}(T)
      = ((T d/dT + 3)^2 + t^2) K_{it}(T).

The manuscript currently treats the divisor/Bessel expansion mainly as an explicit arithmetic
normal form.  But `lambda_t(n)` has a much more rigid meaning.

## 2. The divisor coefficient is exactly the Eisenstein Hecke eigenvalue

For the weight-zero nonholomorphic Eisenstein series of `PSL_2(Z)`, the completed Fourier
expansion is

    E*(X+iy,s)
      = xi(2s) y^s + xi(2-2s) y^(1-s)
        + 2 sum_{n != 0}
            |n|^(s-1/2) sigma_{1-2s}(|n|)
            sqrt(y) K_{s-1/2}(2 pi |n| y) e(nX).

On the unitary principal series

    s = 1/2 + it,

its nonconstant coefficient is exactly

    n^(it) sigma_{-2it}(n) = lambda_t(n).

Equivalently,

    T_n E(.,1/2+it) = lambda_t(n) E(.,1/2+it)

in the standard Hecke normalization.

So the arithmetic coefficient in the Riemann Wigner distribution is not merely a divisor
sum.  It is the unramified `GL_2` principal-series Hecke eigenvalue.

This is a direct representation-theoretic bridge between the current arithmetic-principal-
series program and the Riemann Fourier/Wigner kernel.

## 3. Exact differential identity

Put

    y = e^(2a),
    D_y = y d/dy,
    E_t(X,y) = E*(X+iy, 1/2+it).

Pairing the `n` and `-n` Fourier modes gives

    E_t(X,y)
      = constant term
        + 4 sqrt(y) sum_{n>=1}
            lambda_t(n) K_{it}(2 pi n y) cos(2 pi n X).

The horizontal second derivative kills the constant term:

    -d_X^2 E_t(X,y)
      = 16 pi^2 sqrt(y) sum_{n>=1}
          n^2 lambda_t(n) K_{it}(2 pi n y) cos(2 pi n X).

Now observe the half-density shift.  If `T=2 pi n y`, then

    (D_y + 5/2)[sqrt(y) K_{it}(T)]
      = sqrt(y) (T d/dT + 3) K_{it}(T).

Therefore

    ((D_y+5/2)^2+t^2)[sqrt(y)K_{it}(T)]
      = sqrt(y) B_t(T).

Evaluating at `X=0` gives the exact identity

    boxed:

    W_Xi(a,t)
      = (y^2/4)
        [ ((D_y+5/2)^2+t^2)
          (-d_X^2) E_t(X,y) ]_{X=0},

    y=e^(2a).

No zeta-zero information enters this calculation.

Thus Riemann's Wigner distribution is a fixed differentiated principal-series Eisenstein
wave evaluated on the imaginary axis.

## 4. The Casimir removes the explicit spectral parameter from the differential operator

The completed Eisenstein series obeys the hyperbolic Laplace equation

    -y^2 (d_X^2 + d_y^2) E_t
      = (1/4+t^2) E_t.

Let

    f_t = -d_X^2 E_t.

Since the horizontal derivative commutes with the Laplacian, `f_t` obeys the same equation.
Expand

    (D_y+5/2)^2+t^2
      = y^2 d_y^2 + 6y d_y + 25/4+t^2.

Using the eigenvalue equation gives

    boxed:

    ((D_y+5/2)^2+t^2) f_t
      = -y^2 d_X^2 f_t + 6y d_y f_t + 6 f_t.

Hence

    boxed:

    W_Xi(a,t)
      = (y^2/4)
        [ y^2 d_X^4 E_t
          - 6y d_y d_X^2 E_t
          - 6 d_X^2 E_t ]_{X=0}.

The explicit `t^2` has disappeared from the differential operator.  The spectral parameter
now lives only in the principal-series state itself.

That is a substantial simplification: the same fixed geometric differential observable is
evaluated on every unitary Eisenstein state.

## 5. Why this matters for the RH positivity problem

Jensen's exact criterion in the current manuscript is

    RH
      <=>
      4 eta int_R a sinh(2 eta a) W_Xi(a,t) da >= 0

for all real `t,eta`.

Substituting the Eisenstein identity turns the missing sign theorem into a geometric
positivity statement for one fixed differential observable of the unitary Eisenstein
principal series.

This is much closer to a representation-theoretic positivity problem than the raw theta
kernel suggests.

The Hecke coefficients are generated by self-adjoint commuting Hecke operators on the
unitary principal series, and `E(.,1/2+it)` lies in the continuous spectral family of the
self-adjoint hyperbolic Laplacian.  The exact remaining issue is whether the **specific
Jensen-weighted differential observable** above has a positive realization (or a square)
after the required regularization at the cusp.

## 6. Immediate caution: unitary Eisenstein theory does not automatically give the sign

The ordinary Wigner distribution of an Eisenstein state is not pointwise positive.  In
microlocal automorphic theory one typically uses a positive/Friedrichs symmetrization to
replace the raw Wigner distribution asymptotically.  Therefore

    principal-series unitarity

by itself does **not** imply

    W_Xi(a,t) >= 0.

That would repeat the same mistake already ruled out elsewhere in the program: ambient
unitarity is weaker than the polarized positivity needed for RH.

The useful fact is different: the exact Riemann kernel has now been embedded into a canonical
unitary automorphic representation where stronger tools are available (Hecke self-adjointness,
Casimir factorization, Maass raising/lowering operators, Rankin--Selberg, Kuznetsov, and
positive microlocal quantizations).
